# The Millionaire Game 2.0

<p align="center"><img src="docs/screenshots/logo.png" width="260" alt="Who Wants to Be a Millionaire logo"></p>

A *"Who Wants to Be a Millionaire?"* game for live shows at home, at events, or on a stream, built around the
Regis Philbin era. It runs from a control panel, with separate screens for the host, the contestant and the
audience, and the audience can play along on their phones.

This page is a look at the game in pictures. **The game isn't available for download.**
